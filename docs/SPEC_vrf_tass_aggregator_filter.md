# Спека: отсечение агрегатора vrf.tass.ru по URL-паттерну

Статус: реализовано 2026-08-28 (инцидент «обзоры в выдаче» 28.08)

## Контекст

06:00-прогон 28.08 ушёл из старого образа (без фильтра обзоров `2abcc0f`), в
выдачу попали REVIEW-сигналы и страницы агрегатора `vrf.tass.ru` — региональные
архивы СМИ («Популярные новости России сегодня», перепечатки sever-press-ru и
пр.), классифицированные как NEW_DOCUMENT/AMENDMENT из-за маркеров в заголовках
перепечаток.

## Проблема

`vrf.tass.ru` — агрегатор региональных СМИ, а не источник публикаций о событиях
по НПА. Даже с фильтром обзоров такие страницы проходят, если в перепечатанном
заголовке есть конкретный маркер («изменения», «выплаты»).

## Предполагаемый фикс

Расширить `_EXCLUDED_URL_PATTERNS` в `parser/filters.py`:

```python
re.compile(r"^https?://(?:www\.)?vrf\.tass\.ru/"),
```

Домен целиком: весь контент vrf.tass.ru — перепечатки региональных СМИ
(`<регион>/<издание>-ru/<id>`), собственных публикаций о событиях НПА там нет.

## Как воспроизвести

Сигналы 183 (`vrf.tass.ru/arxangelskaia-oblast/region29-ru/1372313`) и 182
(`vrf.tass.ru/ianao/sever-press-ru/13727476-...`) — «Популярные новости России»,
AMENDMENT/NEW_DOCUMENT вместо REVIEW.

## Ретроактивная часть

Сигналы 170/171/182/183 отвергнуты на проде напрямую (rejection_reason=
`cleanup_20260828_aggregator`) — 28.08, по аналогии с
SPEC_retroactive_signals_cleanup.
