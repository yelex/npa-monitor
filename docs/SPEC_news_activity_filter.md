# SPEC: Фильтр «новость о деятельности» (AMENDMENT-мусор из СМИ)

## Статус
- [x] Done: реализовано, ревью claude (блокеры «вследствие»/«прокуратура» + NPA-lock закрыты), смоук 6/6

## Контекст
Сигналы из новостных СМИ (tass, ria, rg) иногда классифицируются как AMENDMENT,
хотя это новости о деятельности чиновников, без изменения НПА. Примеры из боя
(оба отклонены вручную, rejection_reason=NOT_NPA):
- sig 170: «Голикова рассказала об обработке обращений от участников СВО» (ria.ru)
- sig 171: «Голикова: правительство решило 96% обращений участников СВО» (tass.ru)
- sig 175: «Брянчанка оформила фиктивный брак... незаконно получила 1,4 млн» (rg.ru)

## Проблема
Эксперт вручную отсеивает мусор. Причины попадания: классификатор видит ЖС-слова
(«участников СВО») в новостном заголовке и не требует признаков собственно НПА.

## Предполагаемый фикс
Эвристический pre-filter в `parser/filters.py` (по аналогии с фильтром обзоров
`2abcc0f` и vrf.tass `bb416e5`), применяется к сигналам из новостных источников
(tass/ria/rg; НЕ трогаем sfr.gov.ru, mos.ru, pravo.gov и пр. первоисточники):

1. **Глаголы речи/деятельности в заголовке**: рассказала, заявила, сообщила,
   объявила, пообещала, пояснила, рассказала о, рассказала об и т.п. рядом с
   ФИО-паттерном или должностью → reject (NOT_NPA_ACTIVITY).
2. **Цифровые достижения без НПА-признаков**: паттерн «\d+%» / «тысяч ... получают»
   в заголовке при отсутствии реквизитов НПА (№ документа, дата в формате НПА)
   в заголовке И описании → reject.
3. **Криминал/казус**: оформила, незаконно, мошенниц, приговор, следствие,
   прокуратура, дело о → reject.
4. Спорные (не уверен) → не фильтровать, оставить эксперту (precision-over-recall:
   лучше один лишний сигнал эксперту, чем потерянный настоящий НПА).

Логика reject-причины: фиксированный `rejection_reason` (например,
`not_npa_activity`), чтобы отличать от ручной чистки и считать статистику.

## Как воспроизвести
- Юнит: заголовки sig 170/171/175 → отфильтрованы; заголовок «Внесены изменения
  в постановление о выплатах участникам СВО № 1234» → проходит.

## Вне scope
- LLM-классификация новостей; обучение классификатора; фильтрация Yandex Search
  выдачи (отдельно, если мусор повторится там).
