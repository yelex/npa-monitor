# SPEC: E2E write-back (SPEC_result_edit) — карточка с чекбоксами → применение → экспорт KB

Статус: к исполнению (решение Алексея 2026-08-28 «Давай»).

## Контекст
Write-back реализован (75af72b), ревью-фиксы применены (6ef1d23: html.escape,
invalidate_kb_cache). Юнит/интеграционные тесты зелёные (390 passed). Живой E2E
цепочки «результат агента с changes[] → чекбоксы в TG → Применить → measure_overrides
→ автоэкспорт KB» не было.

## Сценарий
1. **Деплой** кода бота в прод: rsync → `docker compose build bot && docker compose
   up -d bot` (код в образе, restart не подхватывает — INCIDENT 27.08).
2. **Синтетический сигнал**: в БД создаём сигнал IN_PROGRESS с `signal_type=change`,
   `measure_id` = реальная мера из `benefits_knowledge_base.json`,
   `measure_row_hash` = её `row_hash` из KB (как если бы аналитик прошёл FSM
   Фазы 12; сам FSM уже проверен E2E sig-155, здесь тестируется только write-back).
3. **Синтетический результат**: файл `<task_id>.json` в spool `results/`,
   schema_version=3, status=done, `changes[]` с 2–3 полями реальной меры
   (одно значение с `<` и `&` — заодно проверяем экранирование в бою).
4. Скан-луп (≤5 мин) → карточка details + карточка диффа с чекбоксами в TG.
5. **Аналитик (Алексей)**: ✅ на одно поле, ✏ на другое (своё значение), 🗑 на
   третье → «Применить выбранное».
6. Проверки после «Применить»:
   - ответ бота с итогом (applied/edited/deleted/skipped);
   - `measure_overrides` в БД: строки по выбранным полям, `changed_by` = uid;
   - `signal_results.selection` сохранён, переживает рестарт;
   - `benefits_knowledge_base.json` перезаписан: значения мер обновлены,
     `row_hash` пересчитан;
   - повторное «Применить» (если клавиатура ещё жива) → конфликт по base_row_hash
     → STALE/конфликт-месседж, ничего не применилось (проверка атомарности в бою —
     опционально).
7. Сигнал остаётся IN_PROGRESS («Применить» ≠ завершение), `/complete` — по желанию.

## Критерии готовности
- [ ] Карточка с чекбоксами доставлена автоматически.
- [ ] «Применить» → overrides в БД + KB-файл обновлён с новым row_hash.
- [ ] Значение с HTML-спецсимволами не сломало сообщения.
- [ ] Сигнал не закрылся автоматически.

## Что НЕ входит
- Коннектор npa-somas (транспорт уже проверен sig-155) — результат синтетический.
- Флаг «правлено вручную» в KB (вне MVP).
