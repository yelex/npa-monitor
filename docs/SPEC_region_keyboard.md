Статус: **реализовано и проверено (2026-08-25, коммит `45c248d`)**.

## Итоги

- Тесты: **350/350 ✅** (независимый прогон).
- Ревью Claude против спеки: **вердикт OK**, критичных нет. Проверено: буквы только
  существующие (~20, 3 ряда), callback в 64 байтах с запасом (максимальный code —
  40 симв.), пагинация по 8 + «Назад к буквам», выбор ведёт в общий

- Некритичные (зафиксировано):
  - aliases ищутся только в ступени 1 (подстрока); докстринг/спека говорили
    «обе ступени» — аббревиатуры не склоняются, до лемма-этапа не доходят.
  - `scripts/gen_regions_yaml.py` не переносит aliases при регенерации —

  - Тесты алиасов: явно проверен `хмао`; остальные покрыты общим тестом
    (`>=5 записей с aliases`), можно расширить.

## Контекст

Сейчас выбор региона вне РФ/Москвы требует «Другое» + текстовый ввод. Это неудобно:
аналитик не помнит точное имя региона в справочнике, аббревиатуры (ХМАО) не
находятся, на мобильном ввод текста медленнее тапа. У Wishlist пользователя:
алфавитный навигатор → список регионов кнопками.

## Решение

### 1. Шаг «Регион»: алфавитный навигатор

- Клавиатура шага `ask_region`: `[РФ] [Москва] [Не определён]` (как сейчас,
  быстрый путь) + строка(-и) кнопок букв.
- Буквы — только те, что реально есть в `regions.yaml` (прописные кириллические
  первые буквы `name`, кроме РФ/Москвы/undefined). Ожидаемо ~25-30 букв —
  разбить на 2-3 ряда по 8-10 кнопок (`regletter:{sig_id}:{Б}`).
- Тап на букву → список регионов на эту букву: имя (короткое, обрезка ~40
  символов), пагинация по 8 как в саджесте мер (`regpage:{sig_id}:{letter}:{n}`),
  кнопка «⬅ Назад к буквам».
- Выбор региона из списка → `_advance_to_signal_type` (как при 1 матче сейчас).
- Текстовый ввод в `ask_region` оставить как fallback (текущий `on_region_manual`
  не трогаем) — упоминание в подсказке можно убрать, но обработчик остаётся.

### 2. Aliases для аббревиатур

- `regions.yaml`: опциональное поле `aliases: []` у записи региона
  (например, `хмао`, `янао`, `спб`, `рк` для Республики Крым и т.п.).
- `find_region_matches` (обе ступени) ищет и по `aliases` (casefold-подстрока).
- Генератор aliases — вручную для ходовых аббревиатур (~10-15 штук), не
  автоматически. Заполнить минимум: ХМАО, ЯНАО, СПб, АО для автономных округов
  не надо (двусмысленно) — только однозначные.

### 3. Кнопка «Другое»

- Убирается — вместо неё буквенный навигатор. Кнопки `reg:{sig_id}:rf`,
  `reg:{sig_id}:moscow`, `reg:{sig_id}:undefined` сохраняют формат.

## Проверка

- Юнит: клавиатура букв (только существующие буквы, без регионов вне
  справочника), пагинация списка по букве, выбор из списка → флоу, aliases
  («хмао» находит ХМАО-Югру), назад к буквам, текстовый fallback не сломан.
- Ручной: /digest → ✅ → ссылка → ЖС → буква «Х» → ХМАО-Югра → тип сигнала →
  саджест мер показывает ханты-мансийские меры.

## НЕ входит

- Поиск по подстроке кнопками (остаётся текстом).
- Автогенерация aliases.
- Изменение справочника регионов (только поле aliases).
